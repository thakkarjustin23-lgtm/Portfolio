# Justin Thakkar's Portfolio Website

A premium, dark-themed personal portfolio showcasing achievements in innovation, robotics, public speaking, and athletics.

## 🎨 Design System

**Color Palette - "Noir & Gold":**
- Background: #0d0d0d (near-black)
- Surface: #1a1a1a (card/noir)
- Primary Gold: #c9a84c
- Soft Gold: #f0d78c
- Text: Off-white (#f5f5f0)
- Muted: #b3b3b3

**Typography:**
- Display: Urbanist (bold, tight tracking)
- Body: Epilogue (clean sans-serif)
- Labels: Uppercase, wide tracking

## 🏗️ Project Structure

```
src/
├── components/
│   ├── Navigation.tsx      # Sticky header with nav links
│   ├── Hero.tsx            # Hero section with headline
│   ├── StatsBar.tsx        # 4-tile stats display
│   ├── Achievements.tsx    # Bento grid layout
│   ├── Story.tsx           # Two-column story section
│   ├── LinkedIn.tsx        # LinkedIn CTA
│   └── Contact.tsx         # Contact & footer
├── App.tsx                 # Main app component
├── main.tsx                # Entry point
└── index.css               # Global styles & utilities
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```

## 📋 Features

✅ **Responsive Bento Grid Layout** - Adaptive grid system (6 columns desktop, 1 mobile)
✅ **Smooth Scrolling Navigation** - Sticky header with section links
✅ **Premium Dark Theme** - Noir & Gold color palette
✅ **Achievement Cards** - Featured hero cards with decorative orbs
✅ **Stats Bar** - 4 key metrics display
✅ **Story Section** - 2-column layout with narrative
✅ **Social Integration** - LinkedIn profile link
✅ **Contact CTA** - Email link with styled button
✅ **Animations** - Hover effects, smooth transitions
✅ **Mobile Optimized** - Full responsiveness

## 🎯 Sections

1. **Navigation** - Sticky header with logo, nav links, CTA
2. **Hero** - Headline, subheading, overline, grid background
3. **Stats Bar** - 4 tiles: Olympiad Medals, Audience, Age, Grade
4. **Achievements** - Bento grid with 8 achievement cards
5. **Story** - "Curious by default. Competitive by habit." narrative
6. **LinkedIn** - Professional profile CTA
7. **Contact** - Call-to-action and footer

## 🛠️ Tech Stack

- **React 19** - UI library
- **TanStack Start** - Meta framework
- **Tailwind CSS v4** - Utility-first styling
- **Lucide React** - Icon library
- **TypeScript** - Type safety

## 📱 Responsive Breakpoints

- **Mobile**: Single column (< 640px)
- **Tablet**: Multi-column (640px - 1024px)
- **Desktop**: Full bento grid (1024px+)
